# 🧪 Химия

## Темы

```dataview
TABLE WITHOUT ID
    file.link AS "Тема",
    chapter AS "Глава",
    paragraph AS "§",
    status AS "Статус"
FROM "01 Конспекты"
WHERE type = "chemistry-topic"
SORT chapter ASC, paragraph ASC
```

## В работе

```dataview
TABLE WITHOUT ID
    file.link AS "Тема",
    paragraph AS "§"
FROM "01 Конспекты"
WHERE type = "chemistry-topic"
AND status != "ready"
SORT file.name ASC
```

## Готовые темы

```dataview
LIST
FROM "01 Конспекты"
WHERE type = "chemistry-topic"
AND status = "ready"
SORT paragraph ASC
```
